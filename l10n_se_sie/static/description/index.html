SIE

SIE, Standard import och Export.


 




Instruktioner

Du hittar sie export funktionen Fakturering -> Konfiguration -> Export/Import SIE-filer.

Export

Sie Type används för att välja ifall man vill bara ha transaktions poster eller ifall man vill ha transaktions poster och #IB/#UB/#RES

Fältet under "TRANSAKTION" används för att filtrera vilka transaktions poster som ska exporteras.

Fälten under "INSTÄLLNINGAR FÖR IB/UB/RES-POSTAR" så väljer man för vilka räkneskaps år som #IB/#UB/#RES ska inkludera.
I Odoo 17 används kontotyperna för att bestämma vad som är ett balans och resultat konto enligt följande:

Balanskonton

  • asset_receivable (Fordringar)
  • asset_cash (Bank och kontant)
  • asset_current (Omsättningstillgångar)
  • asset_non_current (Inventarier)
  • asset_prepayments (Förbetalningar)
  • asset_fixed (Anläggningstillgångar)
  • liability_payable (Skulder)
  • liability_credit_card (Kreditkort)
  • liability_current (Kortfristiga skulder)
  • liability_non_current (Långfristiga skulder)
  • equity (Eget kapital)
  • equity_unaffected (Nuvarande årliga förtjänster)

Resultatkonton

  • income (Nettoomsättning)
  • income_other (Övriga rörelseintäkter)
  • expense (Utlägg)
  • expense_depreciation (Avskrivning)
  • expense_direct_cost (Förändring av lager av produkter i arbete, färdiga varor och pågående arbete för annans räkning)

Övrigt

  • off_balance (Utanför balansräkningen) - Detta är varken ett balans- eller resultatkonto, utan används för poster som inte påverkar balans- eller resultaträkningen direkt.

Import

Innan import så kan man sätta vilken journal den ska in i.

Det går också sätta ifall en specifik serie ska bli en specifik journal.


Innan man importerar så kan det vara bra att köra "Skanna efter saknade konton" då den kommer läsa igenom filen och hitta konton som saknas. Dem blir sedan listade och man kan sätta namn, typ och om dem är avstämingsbara innan man klickar på "Skapa Konton" för att skapa dem.


När allt är uppsatt så klickar man på "Send" för att importera filen.
